# 筑梦企服客户管理系统

一个使用 React + Vite 开发的简体中文客户管理网页版。无需后端或数据库，适用于电脑浏览器。

## 启动预览

需要 Node.js **22.12+**（或 20.19+）及 npm，推荐 Node.js 24。

在项目目录打开终端，首次使用执行：

```sh
npm ci
npm run dev
```

根据终端提示在浏览器打开地址。默认地址为 `http://localhost:5173`；端口被占用时会明确报错。使用 `Ctrl+C` 停止服务。

在本云环境中，仓库位于 `/workspace/zhumeng`，依赖已安装。如需重新安装并遇到默认 npm 缓存目录权限问题，可执行：

```sh
npm ci --cache /workspace/.npm-cache
```

云环境内的服务与自己电脑上的 localhost 并非同一台机器。若在自己电脑运行，请先下载或克隆此仓库，在仓库目录执行上面的命令。

## 已实现功能

- 客户列表：姓名、公司、电话、状态和创建时间，按创建时间倒序展示，每页 8 条。
- 新增与编辑：姓名、公司、电话为必填项，邮箱及备注为选填项；保留原创建时间。
- 删除前二次确认，取消时不删除数据。
- 按姓名、公司或电话搜索，可同时按潜在客户、跟进中、已成交筛选。
- 客户总数、潜在客户、跟进中、已成交和成交率实时统计；点击统计卡片可筛选。
- localStorage 持久保存；同一来源的浏览器标签页之间同步数据变化。
- JSON 备份导出和导入；导入前验证格式并确认，相同 ID 保留当前记录，新增记录合并。
- 存储失败时明确提示，不假报保存成功；检测到损坏数据时暂停写入，允许导出原始备份。
- 桌面管理后台布局及窄屏适配，支持弹窗键盘操作。

首次使用为空列表，不会混入虚构客户。

## 数据保存须知

客户数据保存在当前浏览器、当前访问来源的 localStorage 中，键名为 `zhumeng-crm:v1`。无需登录，应用不会把客户资料上传至服务器。

**请定期使用「数据与备份」导出备份。** 清除浏览器数据、更换浏览器、设备、协议、域名或端口后，不会自动显示原来的资料。隐私模式也可能在关闭窗口后清除数据。备份包含客户联系方式，请妥善保管。此版本没有账户认证、跨设备同步或多用户权限控制。

## 构建与生产版本检查

```sh
npm run build
npm run preview
```

构建文件生成在 `dist/`，可部署到静态网站托管平台。`npm run preview` 默认使用 4173 端口，用于本地检查构建产物，不是生产托管服务。

## 自动化测试

```sh
npm test
```

浏览器测试使用 Playwright，覆盖增删改、刷新保存、统计、搜索、筛选、分页、备份、存储异常、多标签页同步和窄屏布局。测试使用隔离的浏览器上下文，不会改动真实客户数据。

本云环境会自动使用 `/usr/bin/chromium`。其他机器首次运行测试时，可以执行 `npx playwright install chromium` 安装测试浏览器，也可通过 `CHROMIUM_PATH` 指定已安装的 Chromium 路径。普通开发和构建不需要安装测试浏览器。

## 文件说明

- `src/App.jsx`：客户管理界面、表单、统计、本地数据和备份逻辑。
- `src/styles.css`：后台布局、配色、表格、弹窗及响应式样式。
- `src/main.jsx`：React 入口。

## 云端预览显示 ERR_CONNECTION_REFUSED 时

浏览器中的 `localhost` 表示浏览器所在的电脑，而不是 Codex 云端机器。云端服务返回 HTTP 200，也不代表自己电脑能直接访问。当前提供的 Codex 云环境工具没有公网预览地址或端口转发接口，不能把终端打印的 localhost 当成公网入口。服务进程也不保证在任务停止、环境休眠或重建后继续运行。

开发脚本已固定为 `vite --host 0.0.0.0 --port 5173 --strictPort`。端口占用时会明确报错，避免静默切换到别的端口。

### 无需命令的网页部署

本次已在 `artifacts/zhumeng-crm-dist.zip` 准备好静态网站部署包：

1. 下载 ZIP 并解压，确认文件夹内有 `index.html` 和 `assets`。
2. 在浏览器打开 Netlify Drop：`https://app.netlify.com/drop`，如提示登录则先登录。
3. 上传解压后的整个文件夹，等待平台提供实际的 HTTPS 网址。
4. 打开平台生成的网址即可使用；这个网址可用于其他浏览器或设备，客户资料仍各自保存在各自浏览器中。

部署无需后端，无需填写 API 密钥；上传的是网站程序，不包含浏览器中的客户资料。固定使用同一网站地址，并定期导出客户备份。

### 独立 HTML 预览

执行 `npm run package:preview` 会构建并生成：

- `artifacts/zhumeng-crm-preview.html`：内嵌 JS、CSS 和图标的独立 HTML，可下载后用普通桌面浏览器打开，无需启动 Node.js。
- `artifacts/zhumeng-crm-dist/`：用于静态网站托管的完整目录。

独立 HTML 已在 HTTP 浏览器上下文中验证，无需加载外部资源。当前云端 Chromium 的管理策略禁止 `file://`，因此未在此云环境验证双击打开模式；如果自己的浏览器也限制本地 HTML 或存储，请使用上面的静态网站托管方案。独立文件预览只建议试用，请勿把它当作客户资料的唯一备份。
